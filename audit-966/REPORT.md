# Independent release audit — 12 November 2026

This is a limited, risk-focused audit, not a line-by-line verification of the website. No owner-supplied figures are reproduced here.

## Findings requiring review

1. **Privacy: public repository exposes personal financial data.** GitHub reports this repository is public. The current tree contains unrounded owner-supplied figures in legacy source and data; `python3 scripts/privacy_scan.py` reports 11 matches in five files. The deployed dashboard also publishes owner-specific financial inputs and derived outputs under pseudonymous property labels. Removing names and rounding do not establish anonymity against matching public records. The earlier full-precision values are also in public Git history and PR diffs. Excluding paths in `_config.yml` affects the Pages artifact, not repository access, git history, forks, cached copies or PRs. The previously published F13 does not capture all of this distinction. Do not represent the current release as meeting the requested privacy standard. See [GitHub guidance on sensitive data](https://docs.github.com/en/authentication/keeping-your-account-and-data-secure/removing-sensitive-data-from-a-repository).
2. **Recommendation and gain tax are stated too categorically.** The dashboard says selling is the only path to diversification without a capital-gains bill and describes the basis as resetting and sale as having no gain tax. Basis generally is fair market value at death, subject to exceptions; actual inclusion, basis, transaction costs, later price and other facts can change the result. A recommendation based on illustrative rates and an uncertain trust is not a verified prediction. [IRS inherited-property basis](https://www.irs.gov/faqs/interest-dividends-other-types-of-income/gifts-inheritances/gifts-inheritances) and [IRS estate tax FAQ](https://www.irs.gov/businesses/small-businesses-self-employed/frequently-asked-questions-on-estate-taxes).
3. **Eligibility for Proposition 19 is conditional.** Occupancy alone is not enough; the transfer must meet eligible relationship and family-home conditions, including the transferor's principal residence, and timely filing and occupancy rules. The relationship and trust circumstances are not verified. [BOE fact sheet](https://www.boe.ca.gov/pdf/pub801.pdf); [BOE notice](https://www.boe.ca.gov/proptaxes/pdf/lta25015.pdf).
4. **The source-per-row check does not verify a claim.** `verify_safe.py` confirms allowlisted links and structural properties; it does not check that a linked document supports the text or that a property-specific value is officially verified. For example, the flagged utility-estimate row links a general property-assessment publication rather than evidence of actual utility charges. The site's broad “verified” label and source-linked assumption rows should not be read as independent verification. The user's requirement to leave unconfirmed values blank is not fully met by publishing model assumptions as numerical values. [BOE assessment publication](https://www.boe.ca.gov/proptaxes/pdf/pub800-10.pdf).
5. **Exclusion amount is not the remaining allowance for this estate.** The IRS publishes the 2026 basic exclusion of $15 million, but remaining capacity depends on prior taxable gifts, portability, estate composition and other factors. Future amounts and taxes are projections, not verified facts; no estate balance or remaining capacity is established. [IRS estate tax FAQ](https://www.irs.gov/businesses/small-businesses-self-employed/frequently-asked-questions-on-estate-taxes); [IRS estate and gift tax updates](https://www.irs.gov/businesses/small-businesses-self-employed/whats-new-estate-and-gift-tax).
6. **Further integration is not complete.** The board contains a stale in-progress claim and independent work not integrated into the release. An audit of every line, a full remote link check, and validation of every model equation against the user's requirements were not performed in this session. The latest Pages build is reported built at the pre-existing main commit; this does not establish factual accuracy or privacy.

## Checks performed

- `python3 scripts/verify_safe.py`: passed its structural checks for the curated artifact; this is not a factual verification.
- `python3 scripts/privacy_scan.py`: 11 findings in five tracked files, excluding statutory constants and small amounts as specified by that script; not an exhaustive privacy guarantee.
- GitHub API: repository public; Pages source `main:/`; latest existing build successful at the base commit.
- Read the dashboard and flagged page, reviewed IRS and BOE official sources linked above. Did not fetch every remote site link or independently verify all 291 rows.

## Recommended remediation

Urgently contain the public exposure and review the deployment and repository separately. Build a public site from non-sensitive generic examples, without owner-specific financial inputs or reversible projections. Keep private decision inputs and calculations outside the public repository and artifact. Review official-source support per row, distinguish illustrative assumptions from verified facts, and correct the conditional tax language. Removing historical exposure may require repository-owner action, history rewriting, coordination with fork holders, and GitHub support; even these cannot guarantee removal of copies. Do not merge or advertise the release as fully verified until the privacy risk is addressed.
