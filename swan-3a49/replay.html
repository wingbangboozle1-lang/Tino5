2. Prop 19 amount and the taxable value if the heir moves in

If a child makes the inherited family home a principal residence, the old taxable value carries over unless market value is more than the old taxable value plus an adjustable amount, now $1,044,586. Any excess is added. When there is an excess, the new taxable value works out to market value minus the amount, whatever the old taxable value was. If the heir does not move in, the new taxable value is full market value.
