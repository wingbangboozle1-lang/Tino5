Method

  • There are 49 recorded years with every series available: 1977 to 2025.
  • A path is those 49 years laid over 2027 to 2075 in their recorded order, starting from one chosen year and continuing from 2025 back to 1977 when the record runs out. There are 49 paths, one for each starting year.
  • Every path contains the same years, so every path has the same average. Only the order differs. That isolates the effect of timing.
  • All series for a given year stay together. A year of high inflation keeps its own house prices, interest rates and stock returns.
  • Transfers are placed at the end of 2040, 2045 or 2050. The comparison period is the 25 years after.
  • "Recorded order only" results leave out any window that crosses the join from 2025 back to 1977.
  • 2026 itself is not replayed. Levels start from 2026 and the first replayed year is 2027.

Checks run by the build

  • Each published factor equals the lower of 2% and the published California price change, except the 1983-84 row, which the Board lists as 1%.
  • Every table row carries an official source link. Every dollar figure is a multiple of $10 unless it is a statutory amount shown as published.
  • No page contains a name, address, parcel number, postal code or city name for either property.

Correction on record

The data files were typed from the text of the official pages, because the build machine cannot download them directly. They are transcriptions, not downloads.

A first version of the series file was committed with a header saying every value had been copied from the cited pages. That was not true: the pages were not at hand when it was written and most values had been entered from memory. The file was withdrawn before anything was built from it. The pages were then fetched again and the withdrawn values were compared one by one with the official figures. Three differed:
