Methodology and assumptions

Every number on this site is one of six things: verified against an official source, secondary, supplied by the owner, derived by arithmetic, a named assumption, or unverified and left blank. The model itself is a single Python file (scripts/model.py) with every parameter named A1–A29, so any assumption can be changed and the whole analysis regenerated.

Reproducing the numbers

From the repository root:

python3 scripts/model.py regenerates data/model.json. python3 scripts/build_site.py rebuilds pages/. node scripts/verify.mjs checks every table row for a source, checks statuses and internal links, and writes verification-report.json.

No personal data is used anywhere in this repository: the two properties are referred to only as Property A (95014) and Property B (94122), and no names, street addresses, parcel numbers, account numbers or contact details are stored.
