Verification method

Each document was retrieved and read during this session; the date in the table is that retrieval. Where a document could not be retrieved, the row says so and the figure it would have supported is left blank. No figure on this site was written from memory or from a secondary summary. Where a number is arithmetic on a published figure, the row is labelled derived and the arithmetic is shown in the generator (review-092b/_src/engine.py).

The site is regenerated by python3 review-092b/_src/build.py and checked by python3 review-092b/_src/verify.py, which fails the build if any table row loses its source link, if any dollar figure stops being a multiple of $10, if any internal link breaks, or if any personal-identifier pattern appears.

Privacy. No names, street addresses, parcel or account numbers, ZIP codes, phone numbers or e-mail addresses appear anywhere in this site. Both properties are referred to as Property A (to be inherited through a trust) and Property B (already owned). Assessor histories are not published: a series rounded to $10 is still a fingerprint against open county roll data.

Not advice, and not a forecast. Rules and thresholds are those in force or published on 2026-11-13 and can change before a 2040–2050 transfer. Every figure marked assumption is a modelling assumption, not a fact. Figures marked verified are quoted from the official document linked beside them. This page cannot replace legal, tax, appraisal, insurance or investment advice on the actual estate.
