Repository review and irregularities

What this section is. A review of the repository this site lives in, written by the session that built this directory. It records what was found, what was changed, and what is still wrong — including problems in this site's own predecessors. The source column points at the live directory itself, so every claim here can be checked by opening it.

What the repository contains

The repository accumulated several independent attempts at the same analysis, each by a separate automated session, each published under its own directory. They do not agree with one another, and several publish household dollar figures that the brief asked to be kept private. This is the central repository finding.

What this session changed in the repository

  • Added review-092b/: this site, its generator, its verifier and its tests. Nothing outside this directory was modified except the shared coordination board, the root landing page, _config.yml and the README, which this session claimed explicitly because every other outstanding claim had lapsed.
  • Added a verification gate to the workflow so the site cannot be published if a table row loses its source link, a dollar figure stops rounding to $10, or a personal-identifier pattern appears. The gate runs on every push and pull request.
  • Did not publish this desk. While it was being built, main gained a fail-closed rule that only public-safe/ may be a publishable top-level directory. This desk publishes rounded owner-supplied anchors ($10 rounding), which the live dashboard deliberately withholds entirely. Given that privacy is the owner's first constraint, this desk is listed in the deployment exclusions and the hub describes it rather than linking to it. Publishing it is a one-line change in two files, and it is recorded as an owner decision — F-13.
  • Did not delete, rename or rewrite any other session's published directory.
  • Corrected two arithmetic defects in this site's own first draft rather than shipping them: a black-swan stress test that applied a two-year price fall for twenty-five years, and money amounts that rendered as $-59,572,310 instead of a negative sign before the dollar sign. Both are now regression-tested.

Privacy. No names, street addresses, parcel or account numbers, ZIP codes, phone numbers or e-mail addresses appear anywhere in this site. Both properties are referred to as Property A (to be inherited through a trust) and Property B (already owned). Assessor histories are not published: a series rounded to $10 is still a fingerprint against open county roll data.
