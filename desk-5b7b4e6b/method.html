Method and privacy

How the numbers are produced

One model, one source register, one build script. The pages are generated, so a figure cannot drift between pages.

Resampling, not extrapolation

The 49 years from 1977 to 2025 are resampled in contiguous five-year blocks, with wraparound, 1,500 times. A block is drawn as a unit so that the inflation, house-price, equity and interest-rate behaviour of those years arrives together exactly as it happened. Any regime can follow any other. The result is reported as a median with 10th and 90th percentiles, and as the share of futures in which each path leads.

Bands, not points

Every uncertain input is a low / base / high band. The bands are carried through the arithmetic, so a result arrives as a band too. Where a value is unknown the cell is left empty and the row is tagged, rather than filled with a plausible number.

What the model leaves out

  • Mortgages. No debt on either property has been disclosed, so none is modelled.
  • Property B's terminal sale value, because it is the same in every path and would cancel out (flagged F09).
  • The federal deduction for state tax, beyond the cap described on the inheritance tax page.
  • Any behavioural response: the model does not know whether the household would actually stay the course in a bad decade.

Privacy

No name, street address, parcel number, account number or postcode appears on any page, and no city or neighbourhood name is written into visible text. Properties are identified by county only. Money is rounded to the nearest $10; statutory amounts are quoted exactly as published and marked, because a statutory amount is public by nature.

Assessed values are published banded rather than exactly. An assessed value is a matter of public record tied to one parcel, so rounding to the nearest $10 would not prevent it being traced back to the parcel. The exact figures are used inside the model, which is not published, and only banded anchors reach a page (flagged F03).

Rounding protects figures published from now on. It does not change what is already in this repository's history, and rewriting that history is a destructive operation on shared history that only the repository owner should authorise (flagged F19). Earlier directories in this repository were built before the tighter rule and may contain city names and postcodes (flagged F18); this desk does not change them.

Reproducing this desk

python3 desk-5b7b4e6b/_src/build.py regenerates every page. python3 desk-5b7b4e6b/_src/verify.py re-checks them, and python3 -m unittest discover -s desk-5b7b4e6b/_src -p "test_*.py" runs the model tests. The build is deterministic: a fixed seed is used, so re-running it changes nothing.
