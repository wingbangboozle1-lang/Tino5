# Tino5 — Cupertino & San Francisco House Inheritance Decision Site

Anonymized, source-verified decision dashboard for a Cupertino (95014) house inheritance via trust (2040–2050) alongside a San Francisco (94122) rental property. Live vs rent vs sell-and-reinvest.

**Live site (GitHub Pages):** `https://wingbangboozle1-lang.github.io/Tino5/` (after Pages deploy from `main`).

## Pages

- `index.html` — Dashboard (landing)
- `executive-summary.html` — Executive summary
- `inheritance-process.html` — Step-by-step trust inheritance
- `tax-law.html` — Federal / state / local tax law
- `cupertino.html` — Cupertino 95014 deep dive
- `san-francisco.html` — San Francisco 94122 rental economics
- `decision-analysis.html` — Live vs rent vs sell-and-reinvest
- `projections.html` — Year-by-year projections to 2055
- `costs.html` — Insurance, water, electricity, maintenance
- `methodology.html` — Assumptions, formulas, rounding
- `sources.html` — Official source verification log
- `flagged.html` — Flagged for Review (unverified / irregularities)

## Conventions

- **Privacy:** placeholders only (`[DECEDENT]`, `[BENEFICIARY]`, `[TRUSTEE]`, `[TRUST NAME]`, `[APN REDACTED]`). No personal information is published.
- **Rounding:** all dollars to nearest $10.
- **Labels:** Official / Modelled / User-provided / Flagged — see Methodology.
- **Coordination:** see `COORDINATION.md`.

> Planning aid only — not tax, legal, or investment advice. Confirm figures with cited official sources and qualified California professionals.
