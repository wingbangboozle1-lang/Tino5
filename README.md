# Estate decision desk — Property A (Santa Clara County) & Property B (San Francisco)

A source-linked decision analysis for one household: a house expected through a trust around 2040–2050,
alongside a three-unit San Francisco building that the same person **already owns**.

**Live site:** https://wingbangboozle1-lang.github.io/Tino5/

The published artifact is `public-safe/` only. Everything else in this repository is research,
archive, tooling or a shared coordination log and is excluded from the deployment by `_config.yml`.

## Conclusion in one paragraph

Property A is inherited with a stepped-up basis, so a sale near the date-of-death value carries no
capital-gains tax, while its property tax is reassessed unless the heir occupies it and claims the
Proposition 19 family-home exclusion. Renting it out forfeits that exclusion, raising the annual tax on the
modelled 2045 values to about $81,600 against gross rent of about $115,700 — negative after operating costs.
Property B already provides housing and rental income, has no step-up and no reassessment, and would incur a
large tax bill if sold. The baseline is therefore: **inherit A, keep B, sell A unless living in it is worth
several million dollars of forgone wealth.** All figures are generated by `scripts/desk_model.py`.

## Privacy

- No names, street addresses, parcel or account numbers, ZIP codes, e-mail addresses or phone numbers.
- The properties are **Property A** and **Property B**; jurisdiction is stated at county level only.
- The supplied assessment and tax-bill histories are **not republished at any precision**, including
  rounded to $10: those values are public assessor records and remain searchable. Forward-looking anchors
  are banded ($1,000 for assessments, $100,000 for market values) and model output is rounded to $10.
- `scripts/verify_safe.py` enforces the identifier patterns, the rounding rule and the source-link rule on
  every build. It stores no private value.
- Residual risk: this is a public repository. Earlier commits, branches and merged pull requests still
  contain full-precision figures. The deployment excludes the files that hold them; it cannot unpublish
  history. Only the repository owner can decide whether to make the repository private or rewrite history.

## Verification model

| Label | Meaning |
|---|---|
| **verified** | the rule was read on the linked official page on the date shown on the page |
| **derived** | arithmetic on a banded anchor and/or a verified rule, with the formula shown |
| **assumption** | a named model input; sensitivities are published |
| **owner estimate** | supplied informally by the owner; no official evidence |
| **unverified / flagged** | not supportable; the value cell is blank and the item is on the Flagged page |

Every table body row in a data table carries at least one official source link. Statutory amounts are shown
as published and marked; all other money is a multiple of $10.

## Build and check

```bash
python3 scripts/build_desk.py      # regenerate public-safe/ from the model
python3 scripts/verify_safe.py     # structural, privacy, rounding and link checks
python3 scripts/verify_safe.py --json   # also writes verification-report.json
```

No dependencies, no JavaScript on the published pages, no analytics, no forms.
