Step-by-step trust transfer of Property A and the deadline timeline.

Step-by-step: trust inheritance of Property A (illustrative, ~2040–2050)

  1. Death of settlor / trust becomes irrevocable. Trustee identifies trust assets, including Property A.
  2. Obtain date-of-death appraisal. Establishes stepped-up basis (IRC §1014) and the value for any estate-tax return (Form 706 if estate near/above $15,000,000).
  3. File estate-tax return if required. Federal Form 706 due 9 months after death (6-month extension available). California: no state estate/inheritance tax return.
  4. Transfer title from trust to heir. Trustee executes a trustee's deed; record with the county recorder (Santa Clara County).
  5. File Prop 19 claim (BOE-19-P) with the county assessor within 3 years of transfer / before sale, and heir must occupy as primary residence within 1 year to keep the capped reassessment.
  6. File homeowner's exemption (BOE-266) if occupying as primary residence.
  7. Reassessment determined. If Prop 19 conditions met: assessed ≈ factored base year value + $1,044,586 allowance (2025–2027). Otherwise: full reassessment to market value.
  8. Update insurance, utilities, tax billing. Put water, electricity and homeowner/landlord insurance in the heir's name.
  9. Decide hold vs. sell. Run the Scenarios break-even before committing capital.
