Privacy residual, stated plainly

  • This site uses no names, addresses, parcel numbers, account numbers, ZIP codes, e-mail addresses or phone numbers, and it has no forms, cookies, analytics or external scripts.
  • Market values are banded to $100,000 and assessments to $1,000; model outputs are rounded to $10. That is enough to prevent a direct record match, not enough to guarantee anonymity against someone who already knows the family.
  • The public repository's history, earlier branches and merged pull requests still contain full-precision figures. Excluding files from the deployed site does not remove them from git. Only the repository owner can decide whether to make the repository private or rewrite history.
  • The page is marked noindex,nofollow. That is a request to search engines, not access control.
