MODEL / LONG HORIZON

Projection model

A transparent structure for projecting values and carrying costs. No future home price, assessed value, property tax, utility bill, insurance premium, maintenance cost, estate threshold, or tax outcome can be confirmed for 2040–2050 today.

Why the projection cells are blank. An apparent precise forecast would require unsupported choices for appreciation, inflation, local tax rates, rent growth, insurance renewal, repairs, death/transfer date, basis, unit use, and future law. Official government sources establish some formulas, not household-specific future market inputs. User-provided case figures are private and are not included in this public site.

MODEL FORMULAS

Use these only with documented inputs

Market value scenarioFuture value = current independently supported value × (1 + assumed annual growth rate) ^ years

The assumed growth rate is an analyst scenario, not an official forecast. Use low/base/high cases, and label them assumptions. Current/future value inputs are intentionally blank.

Existing assessed value (Prop 13, general case)Next factored base value = prior factored base value × (1 + lesser of CPI change or 2%)

Assessor enrolls the lower applicable value where Prop 8 decline-in-value treatment applies. Ownership changes or new construction can change the base-year value. BOE source ↗

Prop 19 eligible family-home scenarioEligible value limit = transfer-date factored base-year value + then-current adjusted allowance

If market value is above the limit, the excess can be added to taxable value. The allowance is periodically adjusted; the 2025–27 figure must not be extrapolated to 2040–50. BOE source ↗

Tax billAnnual bill ≈ taxable assessed value × local tax rate + parcel-specific charges − applicable exemptions

California’s statewide base is 1% plus voter-approved bonded indebtedness; special assessments and the parcel’s tax-rate area are required to estimate a real bill. BOE source ↗
