Privacy exposure review

Repository and publication-surface audit · 15 November 2026 · values and personal identifiers intentionally omitted

Highest-priority finding: the GitHub repository is public. The repository API reports public visibility, and GitHub Pages is configured from the default branch root. A noindex tag is not access control. Previously committed content may remain retrievable through history, branches, forks, cached pages, and pull-request references even if the current page is edited.

I did not change repository visibility, disable Pages, or rewrite shared Git history: these actions can affect collaborators, detach forks, remove the requested public site, and invalidate existing refs. Containment is therefore not complete.
