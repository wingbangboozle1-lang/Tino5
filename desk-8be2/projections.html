Method

Projections are illustrative: they apply constant assumptions to a rounded reference value and are not a forecast. Home values, rents, costs and inflation are never consistent over 50 years — see Black swan for uneven histories. Every input is labelled assumption or owner input; none is a verified owner figure.

Reference value for Property A: $3,100,000 (owner input, unverified). Growth 5% a year; assessment cap 2%/yr; cost inflation 3%/yr.

Values grown at 5%/yr (assumption); property tax at 1% of value (illustrative); insurance and utilities inflated at 3%/yr. All figures rounded to the nearest $10. Assessed value base is owner data and is not published.
